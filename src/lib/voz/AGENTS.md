- Voice call scripts are editable per company in voz_roteiros (factory key = edited version, custom_* = new); roteirosLigacao compiles steps + "Se X, faça Y" rules into the call objective, so the device protocol stays unchanged.
- Interpret short replies against the last agent question and bound silence retries in the shared progressoVoz helper; never restart completed steps or infer an answer from silence.
- Test voice scripts in-browser via voz-roteiro-teste and add misunderstood replies to step rules through the pure aprimorarRoteiro helpers, saving immediately, so call tests and real-call suggestions feed the same saved scripts.
- Script quality score, escape-rule auto-fix, extra templates, AI-generated drafts and the conversation map come from the pure qualidadeRoteiro helpers; AI drafts and templates open in the editor unsaved, so nothing changes until the user saves.
- Voice scripts are edited in a full-screen WorkflowBuilderLayout (block menu, canvas, properties panel, like Criar Bot) via fluxoRoteiro + FluxoRoteiroVoz, only a view over etapas/condicoes; question guidance checks live in the pure validacaoPergunta helpers; "Disparar workflow" blocks compile to a [FLUXO:modulo:id] marker that voz-dispositivo dispatches on call end, so devices stay unchanged.
- Sales techniques (BATNA, mirroring, anchoring…) live in the pure tecnicasComerciais catalog; applying one only appends its rule to the step and tags etapa.tecnicas, and department templates in qualidadeRoteiro replace the old factory scripts in the list (factory ones stay as device fallback), so call compilation is unchanged.
- The "Venda & Negociação de Estoque" block stores etapa.venda and compiles to a [VENDA:d;s;f] marker; _shared/catalogoVenda turns it into the live product catalog (estoque, preço, mínimo) plus seller rules in voz-dispositivo and voz-roteiro-teste, and voz-ia-turno only auto-transfers on explicit human requests in that mode, so devices stay unchanged.
- Live AI-call monitor (MonitorChamadasIa): "listen" dials the agent's PBX spy code + AI extension via Pilar Fone; "take over" sets voz_chamadas.assumir_pedido_em, which voz-dispositivo turns into a forced goodbye+[TRANSFERIR] on the next turn, so devices need no update.
- voz-dispositivo ignores a device "[SILENCIO]" turn that arrives before the last AI line could have been heard plus a minimum wait (_shared/silencioVoz), returning an empty reply, so older device builds stop saying "não ouvi" before the client answers.
