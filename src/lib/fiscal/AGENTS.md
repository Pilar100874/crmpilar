- Fiscal regime options and certificate-validity rules live in src/lib/fiscal; A1 certificates are parsed in-browser, stored in the private certificados-digitais bucket per estabelecimento/unidade, and passwords go to unidade_certificado_senhas (write-only for clients) so they are never read back in the UI.
- Item taxation (CFOP, CST/CSOSN, ICMS/ST/DIFAL/FCP, IPI, PIS/COFINS) comes only from the external Systax engine via the systax-calcular function; motorFiscal.ts builds the request from saved company/unit/product fiscal fields and normalizes the reply. Credentials live in systax_config (write-only RPCs). There is no internal rule table (regras_fiscais is deprecated).
