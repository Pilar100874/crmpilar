- Fiscal regime options and certificate-validity rules live in src/lib/fiscal; A1 certificates are parsed in-browser, stored in the private certificados-digitais bucket per estabelecimento/unidade, and passwords go to unidade_certificado_senhas (write-only for clients) so they are never read back in the UI.
- Item taxation (CFOP, CST/CSOSN, ICMS/ST/DIFAL/FCP, IPI, PIS/COFINS) comes only from the external Systax engine via the systax-calcular function; motorFiscal.ts builds the request from saved company/unit/product fiscal fields and normalizes the reply. Credentials live in systax_config (write-only RPCs). There is no internal rule table (regras_fiscais is deprecated).
- Fiscal operation types (fiscal_tipos_operacao) map to a Systax operacao_base plus NF-e finalidade/estoque/cobrança; per-order consumidor final, destinação and presença are chosen at invoicing, saved on the order and nota, and resolved by consumidorFinalVenda so Systax and the emitted NF-e agree.
- Unit fiscal fields are entered explicitly; the removed provider's CNPJ lookup must not be called or replaced with guessed fiscal data.
- Transport, payments, unit series and numbering are chosen in the saved NF-e draft and sent through fiscal-engine to the Coletor, so XML uses saved data.
- NF-e de entrada é auditada no navegador: systax-calcular com o fornecedor como emitente e a unidade como destinatária, comparado ao XML pelo puro auditoriaEntrada.ts; nada é salvo nem bloqueia a entrada.
- NF-e lifecycle uses notas_fiscais.situacao (11 states in src/lib/fiscal/situacaoNfe.ts), kept in sync from status/status_sefaz by a DB trigger so legacy writers stay correct; numbers are reserved only via nfe_reservar_numero to avoid duplicates.
- NF-e emission runs exclusively in the desktop Coletor (coletor/fiscal: XML 4.00, XMLDSig with node-forge A1, SOAP mTLS); the CRM queues fiscal_operacoes via fiscal-engine and fiscal-coletor applies official replies. Production stays blocked until real homologation authorization; legacy provider records remain historical and must not be silently re-emitted.
